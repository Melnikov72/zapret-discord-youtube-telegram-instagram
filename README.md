# zapret-discord-youtube-telegram-instagram
Этот репозиторий лишь является запретом, но только с настройками с разблокировки телеграма и инстаграма.  Все сборки в релизах. 
# **Telegram**
 Телеграм использует свой протокол **MTProto 2.0** , из за этого с помощью только одного zapret не починить Telegram Desktop (приложение телеграма для пк). Что можно сделать только с запрет это только запихнуть айпишники с доменами телеги в файл _hosts_ .
